# מדריך למתמחה בפסיכולוגיה תעסוקתית

אתר אינטרנט עם מדריך שלם למתמחה בפסיכולוגיה תעסוקתית, בהתאם לדרישות משרד הבריאות בישראל.

## מקורות

המדריך מבוסס על:
- **Cook (2016)**: Organizational Psychology - Theory and Practice (3rd ed.)
- **Gatewood (2015)**: Applied Psychology in Human Resource Management (8th ed.)
- דרישות התמחות בענף 1 בפסיכולוגיה תעסוקתית - משרד הבריאות

## תוכן המדריך

המדריך כולל 9 מודולים עיקריים:

1. **יסודות פסיכולוגיה תעסוקתית** - הקדמה לתחום
2. **בחירה והערכת כוח אדם** - תהליכי הגיוס והבחירה
3. **הדרכה וצמיחה מקצועית** - פיתוח מיומנויות
4. **ניהול ביצועים** - הערכה ומשוב
5. **מוטיבציה ושביעות רצון** - תיאוריות ויישום
6. **סכסוכים וקשרים בעבודה** - ניהול סכסוכים ולחצים
7. **קריירה וקידום** - תכנון ופיתוח
8. **שינוי ארגוני** - ניהול שינויים
9. **אתיקה ומנהליות** - שיקולים אתיים

## דרישות

- Python 3.7+
- Flask 2.3.3+

## התקנה

1. התקנת התלויות:
```bash
pip install -r requirments.txt
```

2. הרצת האפליקציה:
```bash
python app.py
```

3. פתיחת הדפדפן וגלישה ל:
```
http://localhost:5000
```

## מבנה הפרויקט

```
ai_app/
├── app.py                 # אפליקציה Flask ראשית
├── data.py               # מידע על המודולים
├── requirments.txt       # תלויות Python
├── templates/            # קבצי HTML
│   ├── base.html        # תבנית בסיסית
│   ├── index.html       # דף הבית
│   ├── modules.html     # רשימת מודולים
│   ├── module_detail.html  # פרטי מודול
│   ├── requirements.html   # דרישות התמחות
│   └── about.html       # דף אודות
└── static/              # קבצי סטטיים
    └── style.css        # עיצוב
```

## שימוש

### גלישה בדפי האתר

1. **דף הבית** - סקירה כללית על המדריך
2. **מודולים** - רשימת כל המודולים ותיאור קצר
3. **מודול** - תוכן מלא של כל מודול עם נושאים
4. **דרישות התמחות** - דרישות רשמיות
5. **אודות** - מידע על המקורות

### API

ניתן לגישה לנתונים דרך API:

- `GET /api/modules` - רשימת כל המודולים
- `GET /api/module/<id>` - פרטי מודול ספציפי

דוגמה:
```bash
curl http://localhost:5000/api/modules
```
